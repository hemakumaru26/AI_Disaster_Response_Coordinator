# Contribution Guidelines

## Branch Strategy

main → Stable Code

Feature branches:

- feature/assessment-agent
- feature/backend
- feature/frontend

## Commit Message Format

feat: New Feature

fix: Bug Fix

docs: Documentation

test: Testing

refactor: Code Improvement

## Development Workflow

1. Pull latest code
2. Implement assigned feature
3. Test locally
4. Commit changes
5. Push to GitHub
6. Merge into mainS
