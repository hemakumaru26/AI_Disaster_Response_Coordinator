# Equal Contribution Strategy

To ensure equal participation throughout the project:

- All members participate in project planning and architecture discussions.
- All members contribute to coding, implementation, testing and debugging.
- Every feature is jointly reviewed before merging into the main branch.
- Documentation is updated collaboratively after every milestone.
- GitHub commits are made throughout the project reflecting each member's implemented work.
- Major project milestones are completed through collaborative development and peer review.

---

# Collaboration Workflow

1. Plan the feature together.
2. Implement the assigned module collaboratively.
3. Test the feature as a team.
4. Update documentation.
5. Commit and push the completed feature to GitHub.
6. Review progress before starting the next milestone.
